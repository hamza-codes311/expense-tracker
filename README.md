# Expense Tracker 💰

A simple Expense Tracker built using HTML, CSS, and JavaScript.

## About the Project

Expense Tracker is a web application that helps users manage their income and expenses. Users can add transactions, track their spending, and calculate their remaining balance.

## Features

- Add income transactions
- Add expense transactions
- Calculate total income
- Calculate total expenses
- Display current balance
- View transaction history

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Structure

- `index.html` – Application structure
- `style.css` – Application styling
- `script.js` – Application functionality
